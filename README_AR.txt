OUJR - Android alpha starter

هذه حزمة مشروع أولية تضع واجهة OUJR التجريبية داخل تطبيق Android WebView.
ليست تطبيق رقمنة تطريز مكتملاً ولا تنتج ملف Tajima DST صالحاً للماكينة في هذه المرحلة.

بناء APK:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub باسم OUJR مع الحفاظ على بنية المجلدات.
2) افتح Actions ثم Build OUJR APK ثم Run workflow.
3) بعد نجاح التشغيل نزّل Artifact باسم OUJR-debug-apk وفك ضغطه.
4) ثبّت app-debug.apk على هاتف Android.

النسخة الحالية: رسم أساسي، إدخال صورة، حفظ معاينة PNG وبيانات JSON.
المراحل غير المنجزة: تحويل الصورة إلى مسارات غرز، محرر غرز احترافي، ومحرك DST مختبر ومتوافق مع ماكينة Tajima.
لا تستخدم أي ملف تجريبي على ماكينة الإنتاج قبل التحقق منه ببرنامج تطريز متخصص.
